AudioPlaybackKit 0.12.0 puts a category on every decode and streaming failure, adds telemetry events to
`Player`, narrows the `PlaybackStreaming` and `Player` public API and renames `ItemSource.duration` to
`frameCount`. It decodes four more families (Monkey's Audio, WavPack, DSD, WMA), links FFmpeg against
nothing but libz, and ships GitHub Actions CI with contributor docs.

This is a minor bump at 0.x: it changes public API (below). Decoder PCM moved in three cases, none of
which a conformance golden pins as PCM (the only goldens that changed hold error text and the new formats):

- A seek into the last frames of an item at a fixed output rate no longer plays frames before the target.
  The resampler's flush was handed out whole, so `tone.mp3` at 48 kHz seeked 5 frames from the end gave 17
  frames, not 5 (#163, 763e525; pinned by `OutputFormatTests`).
- An `avcodec_send_packet` error other than allocation failure now skips that packet and decoding goes on.
  Before, such an error was discarded whatever the codec said and, for some codecs, ended the stream as
  EOF (#162, 0c78d1e). Only ENOMEM fails the decode, as in media3. A corrupt stream may therefore yield
  more PCM than before. 8510413 reverts the attempt to end a run of rejected packets as an error, which
  ended the fixtures with trailing `0xDEADBEEF` filler early; trailing garbage still ends at EOF.
- An MP3 with more than 64 KiB of junk before its audio now opens on a forward-only reader, bit-identical to
  the bare file, where it failed to open (#163, 19ba2e2).

Moving Shuttle Podcasts or Shuttle2 over: [docs/migrating.md](https://github.com/timusus/AudioPlaybackKit/blob/0.12.0/docs/migrating.md#migrating-from-011-to-012).

## What changed

- **Structured errors** (#105, [ADR-0029](https://github.com/timusus/AudioPlaybackKit/blob/0.12.0/docs/decisions/0029-structured-errors.md)).
  `StreamDecoderError.failed` and `StreamByteReaderError.failed` carry a `StreamFailure` with a
  `PlaybackErrorCategory` (`io`, `network`, `http(status:)`, `malformed`, `unsupported`, `cancelled`,
  `internal`), the libav `averror` and the `URLError`. `PlaybackError.category` lets an app choose retry
  or skip without unpicking the underlying error. A connection lost during the probe is `.network`, no
  longer "no demuxer recognised the stream". `FFmpegStreamDecoder.error` holds the failure behind a nil
  `nextChunk()`. A failed seek call or codec open records its AVERROR, and a reader failure is consumed once.
- **`PlayerEvent` telemetry** (#161, [ADR-0028](https://github.com/timusus/AudioPlaybackKit/blob/0.12.0/docs/decisions/0028-first-audio-and-buffering-events.md)).
  `firstAudioRendered(index:position:)`, `bufferingStarted(index:position:)` and `bufferingEnded`, as
  media3's `onRenderedFirstFrame` and rebuffer events. Starts and ends alternate; nothing is sent while paused.
- **`Player.bufferedAhead`**: the PCM written past what is heard, as media3's `getTotalBufferedDuration()`.
- **Transport and sources.** `Transport.setNext` and `clearNext` now also drop a next item that decode has
  already passed into; the transport holds at most one next. `ItemSource.release()` is required, with no
  default, so a wrapper that forgets to forward it no longer leaks the download. The transport releases an
  item's source when it lets go of it, and the player releases processor items when it unloads.
- **`isReadyForMoreData` is gone** from the output protocol; only tests read it (#167).
- **`AudioProcessingError`** has three new cases: `inPlaceStageChangedFormat`, `misreportedFrames` and
  `endedWithInputPending`. A processor that breaks its contract fails the item through the transport's
  failure path, where it trapped the app on a precondition (#167).
- **API cleanup.** `ItemSource.duration` is `frameCount`, now required; `PlaybackSuppression.none` is
  `.unsuppressed`; `Player.hasNext` and `hasPrevious` are internal. `usage.md` states the units rule: a
  time is seconds, a count of PCM frames is `Int64` named for frames, byte APIs are offsets.
- **`PlaybackStreaming` narrowed.** `GrowingFileListener.playerWillSeek(to:generation:)` takes seconds;
  `GrowingFileStore`'s `write` and `availableCapacity` seams are `@_spi(Testing)`; `budget` is internal;
  `GrowingFileByteSource` is no longer a `URLSessionDataDelegate`; `removeRetiredRunCache` is removed.
- **Streaming behaviour.** A 2xx response is accepted as media3 does; a 200 to a bounded request from byte 0
  is a range ignored; `Accept-Encoding: identity` is sent on every request and app headers named `Range`
  or `Accept-Encoding` are ignored; certificate, ATS and bad-URL errors fail without the 30 s retry (#164);
  `-1200` is retried; auth headers survive a same-host http to https upgrade. `GrowingFileByteSource`
  takes a `clientCredential` closure for mutual-TLS origins.
- **Short seeks on a growing download** reach the byte source when the target lies past the fetched bytes
  (#113), through `StreamByteReader.fetchedEnd`, instead of reading forward at network rate.
- **FFmpeg links only libz.** The framework no longer links system libraries it does not use
  (ba995f3, de72901); `SYSTEM_LIBS` in `scripts/build-ffmpeg.sh` is `-lz`.
- **`NowPlayingSession` releases the Now Playing session when dropped** and a dropped session never clears
  its successor (#167). Next and previous track register alongside the skip buttons, the rate command gets
  `Float` rates, and elapsed time is not rewritten while the position is held.
- **`Player` fixes.** A refused reactivation after an interruption is a session error; removing a failed
  current loads its successor however it failed; a load with `playWhenReady` takes the session it lacks.
- **AirPlay 2 long-form audio** (#173, [usage](https://github.com/timusus/AudioPlaybackKit/blob/0.12.0/docs/usage.md)):
  the session sets `.playback` with `routeSharingPolicy .longFormAudio`; the seam and tests now pin it.
- **Monkey's Audio, WavPack, DSD (DSF, DFF) and WMA v1/v2** (#171), built into the FFmpeg framework and
  sniffed even when a server sends `application/octet-stream`. DSD decodes to PCM; there is no DoP
  passthrough. Known gaps: WavPack seeking fails with a decode error (#175); APE has no conformance fixture
  and is untested; WMA Pro and Lossless are not built in.
- **CI and contributing** (#170): GitHub Actions run the tests, the conformance bundle and an iOS simulator
  job; `docs/contributing.md` describes the PR checklist and the owner's land and release path.
- **Older Xcode (26.x) compiles**: `withLock` closure result types, `entry(after:)` qualification, the
  `cursor` binding and `ManualPumpTimer`'s properties no longer need a newer compiler.
- **Tests**: a model-based `Player` test against media3 semantics, a seeded chaos run of streaming into the
  decoder, and golden playback dumps through `Transport` (#166, #168 fixed flakes).

## Breaking changes

- `StreamDecoderError.failed(status: Int32)` is `failed(StreamFailure)`, and `StreamByteReaderError.transport(String)`
  is `failed(StreamFailure)`. The C `stream_decoder_open_with` takes a trailing `int *averror`.
- `ItemSource.duration` is `frameCount`, required. `ItemSource.release()` is required.
- `PlaybackSuppression.none` is `.unsuppressed`. `Player.hasNext` and `hasPrevious` are internal.
- `GrowingFileListener.playerWillSeek(toMs:generation:)` is `playerWillSeek(to:generation:)` in seconds.
  `GrowingFileStore.init` with `write`/`availableCapacity` and `WriteFunction` need `@_spi(Testing)`;
  `removeRetiredRunCache` and `GrowingFileStore.budget` are gone from the public API.
- `PlayerEvent` has three new cases: an exhaustive `switch` no longer compiles.
- `isReadyForMoreData` is removed from the output protocol. `AudioProcessingError` has three new cases.

## Upgrading

[docs/migrating.md](https://github.com/timusus/AudioPlaybackKit/blob/0.12.0/docs/migrating.md#migrating-from-011-to-012)
lists each old and new symbol and the call sites in both apps. Neither app matched the changed error
cases, so the error bump compiles unchanged; Shuttle Podcasts needs the `frameCount` rename and the
`playerWillSeek` change.
